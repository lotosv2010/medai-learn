# 03 — 采样参数与推理模型

对应文章：第 03 篇《采样参数与推理模型：temperature 到底在调什么》

## 要验证什么

### 实验 A：temperature 扫描

固定一个 prompt（如「给这款药写一条 30 字以内的用药提醒」），temperature 取 `0 / 0.3 / 0.7 / 1.0`，每档跑 5 次，共 20 条输出。

记录：同一档位内 5 条输出的重复率、偏离程度、是否出现事实偏移。

预期看到：0 档几乎完全一致；1.0 档偶尔出现「不像事实」的表述。

### 实验 B：普通模型 vs 推理模型

一道多步医学计算题（如「按体重折算儿童剂量，并判断是否超过成人上限」），普通模型与推理模型各跑一次。

记录：**正确率 / 耗时 / 思考 token 数 / 总成本** 四项。

预期看到：推理模型答对但贵好几倍；换简单题后两者无差别。

## 怎么跑

```bash
pnpm --filter @medai/labs params
```

## 看到什么算成功

- 一张「temperature 档位 × 输出差异」表
- 一张「普通模型 / 推理模型」四项对比表
- 你能回答：为什么 temperature=0 也不保证完全确定？

## 预算

20 次短调用 + 2 次推理调用，预计 ¥2-3。
