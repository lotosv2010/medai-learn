## 知识点范围

### 第 09 篇：图：Webpack 模块依赖图/拓扑排序/最短路径

**副标题**：邻接表建图、DFS/BFS 遍历、拓扑排序检测循环依赖

#### 一、场景切入：Webpack 模块依赖图与循环依赖

- Webpack 模块图：每个 JS 文件是一个节点，`import` 语句是有向边——tree shaking 是可达性分析，循环依赖检测是环检测
- npm 包依赖：`package-lock.json` 的依赖关系是有向无环图（DAG），出现环就是循环依赖

#### 二、图是什么

- 节点 + 边，可表示任何二元关系（道路、航班、社交关系）
- 有向图 / 无向图；JS 中没有图，用 Object + Array 构建
- 表示法：邻接矩阵（稠密图，O(V²) 空间）vs 邻接表（稀疏图，O(V+E) 空间）——前端用邻接表

#### 三、遍历

- 深度优先 DFS：递归，标记未访问的相邻节点继续 DFS（白灰黑三色）
- 广度优先 BFS：队列，队头出队访问，未访问相邻节点入队
- DFS/BFS 进阶：DFS 记录发现/完成时间（拓扑排序基础）、BFS 记录距离/前溯点（最短路径基础）

#### 四、拓扑排序

- 对 DAG 节点排序使所有边从前指向后——Kahn 算法（BFS，入度为 0 入队）+ DFS 后序
- 图有环则拓扑排序失败，可检测循环依赖（LeetCode 207/210）

#### 五、最短路径 / 最小生成树 / 并查集（只讲思想）

- Dijkstra（贪心，单源最短路径）、Floyd-Warshall（DP，多源最短路径）
- Prim / Kruskal（贪心，最小生成树 MST）
- 并查集（Union-Find）：处理连通性问题，路径压缩 + 按秩合并使 find/union 均摊接近 O(1)

#### 七、前端工程落地

- Webpack ModuleGraph：`lib/ModuleGraph.js` 维护模块间依赖，`getOutgoingDependencies` 返回出边，即图的邻接表
