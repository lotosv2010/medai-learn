# 一、概述
+ 原型模式是一个创建型的模式
+ 基于原有的一个对象创建一个新对象
+ 创建基类的时候，简单差异化的属性放在构造函数中，消耗资源相同的功能放在基类原型中

# 三、代码
```javascript
function Person (name) {
  this.name = name;
  this.getName = function() {
    return this.name;
  }
}
const p1 = new Person('zhangsan');
const p2 = new Person('lisi');
console.log(p1.getName == p2.getName); // false
```

```javascript
function Person (name) {
  this.name = name;
  this.getName = function() {
    return this.name;
  }
}
// 1.复用
Person.prototype.setName = function (name) {
  this.name = name;
}
const p1 = new Person('zhangsan');
const p2 = new Person('lisi');
console.log(p1.setName == p2.setName); // true
```

# 四、JavaScript中的原型
## 函数和对象
+ 函数是一种对象
+ 对象都是通过函数创建的

```javascript
// 函数是一种对象
function Person() {}
console.log(Person instanceof Object);
// 对象都是通过函数创建的
const p1 = new Person();
const o1 = {name: 'test'}
// 上句代码实现等同下面两句
const o2 = new Object();
o2.name = 'test';
console.log(p1);
console.log(o1);
console.log(o2);
```

## prototype
+ 每个函数都有一个属性叫做 prototype
+ prototype 的属性值是一个对象，默认的只有一个叫做 constructor 的属性，指向这个函数本身
+ 每个对象都有一个隐藏的属性[ __proto__](https://www.cnblogs.com/wangfupeng1988/p/3979290.html)，这个属性引用了创建这个对象的函数的 prototype

+ 自定义函数的 prototype 是由 Object 创建，所以它的 __proto__指向的就是 Object.prototype
+ Object.prototype 的 __proto__ 指向的是 null

+ Object.__proto__ 指向  Function.prototype

## instanceof
+ [instanceof](https://www.cnblogs.com/wangfupeng1988/p/3979533.html)
+ instanceof 运算符的第一个变量是一个对象，暂时称为A，第二个变量一般是一个函数，暂时称为B
+ instanceof 的判断规则是：沿着 A 的 __proto__ 这条线来红，同时沿着 B 的 prototype这条线来找，如果两条线能找到同一个引用，即同一个对象，那么就返回 true，如果找到终点还未重合，则返回 false

```javascript
console.log(Object instanceof Function);   // true
console.log(Function instanceof Object);   // true
console.log(Function instanceof Function); // true
```

## 原型链
+ 访问一个对象的属性时，先在基本属性中查找，如果没有，在沿着 __proto__ 这条链向上找，这就是原型链
+ hasOwnPrototype 可以区分一个属性到底是自己的还是从原型中找到

```javascript
function Foo() {
  this.a = 10
}
Foo.prototype.b = 20;
const f = new Foo();
console.log(f.a); // 10
console.log(f.b); // 20
```

## 原型的优势
+ 可以随意扩展
+ 可以重写继承的方法

```javascript
const obj = {};
console.log(obj.toString());
const arr = [1, 2, 3];
console.log(arr.toString());
```

# 五、场景
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>原型模式</title>
  <style>
    * {
      margin: 0;
      padding: 0;
    }
    body {
      margin: 50px auto;
      text-align: center;
    }
    canvas {
      border: 1px solid #ccc;
    }
  </style>
</head>
<body>
  <canvas id="canvas" width="1000px" height="600px"></canvas>
  <script>
    const canvas = document.getElementById('canvas');
    const ctx = canvas.getContext('2d');
    const circles = [];
    function Circle(x, y, radius) {
      this.x = x;
      this.y = y;
      this.radius = radius;
      circles.push(this);
    }
    function getRandomColor() {
      const rand = Math.floor(Math.random() * 0xFFFFFF).toString(16);
      if(rand.length == 6) {
        return `#${rand}`
      } else {
        return getRandomColor()
      }
    }
    Circle.prototype.render = function() {
      ctx.beginPath();
      ctx.arc(this.x, this.y, this.radius, 0, 2 * Math.PI);
      ctx.fillStyle = getRandomColor();
      ctx.fill();
    }
    Circle.prototype.update = function() {
      this.radius--;
      return this.radius > 0;
    }
    canvas.onmousemove = function(event) {
      new Circle(event.clientX, event.clientY, 30);
    }
    setInterval(() => {
      ctx.clearRect(0, 0, 1000, 600);
      circles.forEach(c => {
        c.update() && c.render();
      })
    }, 13);
  </script>
</body>
</html>
```
