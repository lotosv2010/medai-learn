# 04 — 模型选型与成本估算

对应文章：第 04 篇《模型图谱与选型：把成本算清楚（阶段一收官）》

## 要验证什么

纯计算，不调 API。写一个成本估算器：

**输入**：日均调用量 1000 次 / 平均输入 800 token / 平均输出 300 token

**输出 1**：一张表，5 个候选模型（含 1 个推理模型作对照）的「每次成本 / 日成本 / 月成本」

**输出 2**：加入模型路由后（70% 简单任务走小模型 + 30% 复杂任务走大模型）的成本对比，看省了多少

预期看到：单价差 10 倍的模型，月成本差一个数量级；路由能再省一半以上。

## 怎么跑

```bash
pnpm --filter @medai/labs cost
```

## 看到什么算成功

- 两张成本表，数字可直接贴进文章
- 你能用一句话说出结论：**成本是设计出来的，不是省出来的**
