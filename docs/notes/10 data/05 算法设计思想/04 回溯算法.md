# 一、回溯算法是什么
## 概念
+ <font style="color:rgb(51, 51, 51);">backtracking algorithm</font>
+ 回溯算法是**<font style="color:#E8323C;">算法设计</font>**中的一只方法
+ 回溯算法是一种**<font style="color:#E8323C;">渐进式</font>**寻找并构建问题解决方式的策略
+ 回溯算法会先从一个可能的动作开始解决问题，如果不行，就回溯并选择另一个动作，直到将问题解决

# 二、使用场景
## 全排列问题
+ 用递归模拟出所有情况
+ 遇到包含重复元素的情况，就回溯
+ 收集所有到达递归终点的情况，并返回

### 代码实现
`src/algorithm-design/backtracking-algorithm/leetcode.ts`

```typescript
// todo 全排列
export function permute(nums: number[]): number[][] {
  const res: number[][] = [];
  const backtrack = (path: number[]) => {
    // console.log(path, res)
    if(path.length === nums.length) {
      res.push(path);
      return;
    }
    nums.forEach(n => {
      // console.log('n', n)
      if(path.includes(n)) return;
      backtrack(path.concat(n)); // path为引用类型这里要使用concat，返回一个新数组，防止输出结果都为空
    });
  }
  backtrack([]);
  return res;
};
```

+ 要求：

    - 没有重复元素

### 解题步骤
+ 用递归模拟出所有情况
+ 保证接的数字都是后面的数字
+ 收集所有到达递归终点的情况，并返回

### 代码实现
`src/algorithm-design/backtracking-algorithm/leetcode.ts`

```typescript
// todo 子集
export function subsets(nums: number[]): number[][] {
  const res: number[][] = [];
  const backtrack = (path: number[], l: number, start: number) => {
    if(path.length === l) { // 递归结束条件
      res.push(path);
      return;
    }
    for (let i = start; i < nums.length; i++) {
      backtrack(path.concat(nums[i]), l, i + 1);
    }
  }
  for (let i = 0; i <= nums.length; i++) {
    backtrack([], i, 0);
  }
  return res;
};
```
