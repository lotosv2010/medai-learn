# <font style="color:rgb(51, 51, 51);">数据库能够做什么</font>
+ <font style="color:rgb(51, 51, 51);">存储大量数据，方便检索和访问</font>
+ <font style="color:rgb(51, 51, 51);">保持数据信息的一致、完整</font>
+ <font style="color:rgb(51, 51, 51);">共享和安全</font>
+ <font style="color:rgb(51, 51, 51);">通过组合分析，产生新的有用信息</font>

# <font style="color:rgb(51, 51, 51);">数据库的基本概念</font>
## <font style="color:rgb(51, 51, 51);">实体</font>
+ <font style="color:rgb(51, 51, 51);">只要是在客观世界存在的、可以被描述出来的都是实体</font>

## <font style="color:rgb(51, 51, 51);">数据库(DB)</font>
+ <font style="color:rgb(51, 51, 51);">数据库就是数据的仓库，可以存放结构化的数据</font>

## <font style="color:rgb(51, 51, 51);">数据库管理系统(DBMS)</font>
+ <font style="color:rgb(51, 51, 51);">是一种系统软件，提供操作数据库的环境，可以通过数据库管理系统对数据进行插入、修改、删除和查询等操作。</font>

## <font style="color:rgb(51, 51, 51);">SQL</font>
+ <font style="color:rgb(51, 51, 51);">结构化查询语言 专门用来和数据库进行交流的语言,几乎所有的DBMS都支持SQL</font>

## <font style="color:rgb(51, 51, 51);">默认值</font>

+ <font style="color:rgb(51, 51, 51);">我们可以指定某个字段不能不输入，必须提供一个非空的值</font>
+ <font style="color:rgb(119, 119, 119);">姓名字段不能为空</font>

# <font style="color:rgb(51, 51, 51);">实体完整性</font>
## <font style="color:rgb(51, 51, 51);">主键约束</font>
+ <font style="color:rgb(51, 51, 51);">表中一列或者几列组合的值能用来唯一标识表中的每一行，这样的列或者列组合称为表的主键，主键表的数据不同重复。</font>
+ <font style="color:rgb(51, 51, 51);">如果两列或者多列组合起来唯一标识表中的每一行，则该主键又称为"组合键"</font>
+ **<font style="color:rgb(51, 51, 51);">主键的选择标准</font>**
    1. <font style="color:rgb(51, 51, 51);">最少性 尽量选择单个键作为主键</font>
    2. <font style="color:rgb(51, 51, 51);">稳定性 ，由于主键是用来在两个表间建立联接的，所以不能经常更新，最好就不更新</font>

## <font style="color:rgb(51, 51, 51);">外键</font>
+ <font style="color:rgb(51, 51, 51);">成绩表中的学生ID应该在学生表中是存在的 我们应该让成绩表中的ID只能引用学生表中的ID，它们的值应该是一一对应的，也就是说成绩表中的ID是成绩表中的外键，对应学生表的主键 ，这样就可以保证数据的引用完整性</font>

## <font style="color:rgb(51, 51, 51);">唯一约束</font>
+ <font style="color:rgb(51, 51, 51);">唯一约束是指某个字段值是唯一的，在所有的记录中不能有重复的值.</font>
+ <font style="color:rgb(119, 119, 119);">学生的身份证号可以设置为唯一约束</font>

## <font style="color:rgb(51, 51, 51);">标识列</font>
+ <font style="color:rgb(51, 51, 51);">当表中没有合适的列作为主键时可以考虑增加标识列，标识列是一个无实际业务含义的列，仅仅用来区分每条记录。</font>
+ <font style="color:rgb(51, 51, 51);">标识列的值是自动生成的，不能在该列上输入数据</font>

## <font style="color:rgb(51, 51, 51);">外键约束</font>
+ <font style="color:rgb(51, 51, 51);">一个表的外键必须引用另一个表的主键,比如成绩表中的学生ID会引用学生表的主键，课程ID会引用成绩表的主键</font>
    - <font style="color:rgb(51, 51, 51);">主表没有记录，子表中不能添加相应的记录</font>
    - <font style="color:rgb(51, 51, 51);">修改和删除主表记录不能让子表记录孤立，必须相应修改和删除</font>

## <font style="color:rgb(51, 51, 51);">添加约束</font>
```sql
-- 主键约束
ALTER TABLE `student` ADD PRIMARY KEY (`id`);
-- 唯一约束
ALTER TABLE `student` ADD UNIQUE INDEX `uq_idcard` (`idcard`) ;
-- 默认约束
ALTER TABLE `student` MODIFY COLUMN `city`  varchar(50)  DEFAULT '北京' AFTER `age`;
-- 外键约束
ALTER TABLE `score` ADD CONSTRAINT `fk_stuid` FOREIGN KEY (`student_id`) REFERENCES `student` (`id`);
-- 删除约束
ALTER TABLE `score` DROP FOREIGN KEY `fk_stuid`;
```

```sql
CREATE TABLE `student` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `name` varchar(50) NOT NULL,
  `idcard` varchar(18) DEFAULT NULL,
  `age` int(11) DEFAULT NULL,
  `city` varchar(50) DEFAULT '',
  PRIMARY KEY (`id`)
);

CREATE TABLE `course` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `name` varchar(50) DEFAULT NULL,
  PRIMARY KEY (`id`)
);

CREATE TABLE `score` (
  `student_id` int(11) NOT NULL DEFAULT '0',
  `course_id` int(11) NOT NULL DEFAULT '0',
  `grade` float DEFAULT NULL,
  PRIMARY KEY (`student_id`,`course_id`),
  KEY `fk_courseid` (`course_id`),
  CONSTRAINT `fk_courseid` FOREIGN KEY (`course_id`) REFERENCES `course` (`id`),
  CONSTRAINT `fk_stuid` FOREIGN KEY (`student_id`) REFERENCES `student` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8;
```

## <font style="color:rgb(51, 51, 51);">SQL组成</font>
### <font style="color:rgb(51, 51, 51);">DDL（data definition language）是数据定义语言</font>
+ <font style="color:rgb(51, 51, 51);">主要的命令有</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">CREATE</font>`<font style="color:rgb(51, 51, 51);">、</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">ALTER</font>`<font style="color:rgb(51, 51, 51);">、</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">DROP</font>`<font style="color:rgb(51, 51, 51);">等，</font>**<font style="color:rgb(51, 51, 51);">DDL</font>**<font style="color:rgb(51, 51, 51);">主要是用在定义或改变表（TABLE）的结构，数据类型，表之间的链接和约束等初始化工作上，他们大多在建立表时使用</font>

### <font style="color:rgb(51, 51, 51);">DML（data manipulation language）是数据操纵语言</font>
+ <font style="color:rgb(51, 51, 51);">它们是</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">SELECT</font>`<font style="color:rgb(51, 51, 51);">、</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">UPDATE、</font>`<font style="color:rgb(51, 51, 51);">INSERT</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">、</font>`<font style="color:rgb(51, 51, 51);">DELETE`，就象它的名字一样，这4条命令是用来对数据库里的数据进行操作的语言</font>

### <font style="color:rgb(51, 51, 51);">DCL（DataControlLanguage）是数据库控制语言</font>
+ <font style="color:rgb(51, 51, 51);">是用来设置或更改数据库用户或角色权限的语句，包括（</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">grant</font>`<font style="color:rgb(51, 51, 51);">,</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">revoke</font>`<font style="color:rgb(51, 51, 51);">等）语句</font>

### <font style="color:rgb(51, 51, 51);">插入数据行</font>

```sql

```

#### <font style="color:rgb(51, 51, 51);">插入记录</font>

#### <font style="color:rgb(51, 51, 51);">注意事项</font>
+ <font style="color:rgb(51, 51, 51);">每次插入一行数据，不能只插入一部分数据，插入的数据是否有效将按照整行的完整性要求来检验</font>
+ <font style="color:rgb(51, 51, 51);">每个数据值的数据类型、精度、位数必须与要应的列名精确匹配</font>
+ <font style="color:rgb(51, 51, 51);">不能为标识符指定值</font>
+ <font style="color:rgb(51, 51, 51);">如果某字段设置为不能为空，则必须插入数据</font>
+ <font style="color:rgb(51, 51, 51);">插入数据时还要符合检查性约束的要求</font>
+ <font style="color:rgb(51, 51, 51);">有缺省值的列，可以使用DEFAULT关键字来代替插入实际的值</font>

# <font style="color:rgb(51, 51, 51);">存储过程</font>
+ <font style="color:rgb(51, 51, 51);">大多数SQL语句都是针对一个或多个表的单条语句。但是并不是所有的操作都是可以用一条语句来完成的，经常有一些操作是需要多条语句配合才能完成。我们引入的存储过程（Stored Procedure）是一组为了完成特定功能的SQL语句集，经编译后存储在数据库中，用户通过指定存储过程的名字并给定参数（如果该存储过程带有参数）来调用执行它</font>

## <font style="color:rgb(51, 51, 51);">语法</font>
```sql
CREATE PROCEDURE([[IN |OUT |INOUT ] 参数名 数据类形...])
```

## <font style="color:rgb(51, 51, 51);">调用</font>
+ <font style="color:rgb(51, 51, 51);">因为存储过程实际上是一种函数,所以存储过程名后需要有 () 符号(即使不传递参数也需要)</font>

```sql
CALL Avg_Price()
```

## <font style="color:rgb(51, 51, 51);">删除</font>
```sql
DROP PROCEDURE IF EXISTS Avg_Price;
```

## <font style="color:rgb(51, 51, 51);">参数</font>
+ <font style="color:rgb(51, 51, 51);">存储过程并不显示结果，而是把结果返回给你指定的变量</font>

```sql
create procedure sum (in a int,in b int,out result int)
begin
select a+b INTO result;
end

call sum5(1,2,@result);
select @result;
```

```sql
-- 构建一个8388608条记录的数据 

-- 创建用户表
create table user(
  id int,
  username varchar(64),
  userno int
)

-- 创建生成随机字符串的函数
CREATE FUNCTION `rand_string`(n INT) RETURNS varchar(255)
BEGIN 
DECLARE chars_str varchar(100) DEFAULT 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'; 
DECLARE return_str varchar(255) DEFAULT ''; 
DECLARE i INT DEFAULT 0; 
WHILE i < n DO 
SET return_str = concat(return_str,substring(chars_str , FLOOR(1 + RAND()*62 ),1)); 
SET i = i +1; 
END WHILE; 
RETURN return_str; 
END; 


-- 产生随机数字 
create function rand_num() 
returns int(5) 
begin  
declare i int default 0; 
set i = floor(10+rand()*500); 
return i; 
end

-- 创建存储过程，向用户表添加海量数据 

create procedure insert_user(in start int(10),in max_num int(10))
 begin
   declare i int;
   set i=0;
   while i<max_num do
     set i=i+1;
         insert into user(id,username,userno) values((start+i),rand_string(6),rand_num());
   end while;
 end;
call insert_user(1,8388608);
```

## <font style="color:rgb(51, 51, 51);">索引创建的原则</font>
+ <font style="color:rgb(51, 51, 51);">比较频繁作为查询条件的字段应该创建索引</font>
+ <font style="color:rgb(51, 51, 51);">唯一性太差的字段不适合单独创建索引，即使频繁作为查询条件</font>
+ <font style="color:rgb(51, 51, 51);">更新非常频繁的字段不适合作创建索引</font>
+ <font style="color:rgb(51, 51, 51);">不会出现在where子句中的字段不该创建索引</font>
