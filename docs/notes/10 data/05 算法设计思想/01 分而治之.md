# 一、分而治之是什么
+ <font style="color:rgb(34, 34, 38);">Devide and Conquer</font>
+ 分而治之是**<font style="color:#E8323C;">算法设计</font>**中的一只方法
+ 它将一个问题**<font style="color:#E8323C;">分</font>**解成多个和原问题相似的小问题，**<font style="color:#E8323C;">递归解决</font>**小问题，再将结果**<font style="color:#E8323C;">合</font>**并以解决原来问题

# 二、使用场景
## 归并排序
+ 分：把数组从中间一分为二
+ 解：递归地对两个子数组进行归并排序
+ 合：合并有序子数组

> [归并排序](https://www.yuque.com/lotosv2010/front_end/ydm6v7#M4oDq)
>

## <font style="color:rgb(51, 51, 51);">快速排序</font>
+ 分：选基准，按基准把数组分成两个子数组
+ 解：递归地对两个子数组进行快速排序
+ 合：合并有序子数组

> [快速排序](https://www.yuque.com/lotosv2010/front_end/ydm6v7#uHa43)

# 三、LeetCode
## 合并两个有序链表
### 题目
+ [数字大小](https://leetcode-cn.com/problems/guess-number-higher-or-lower/)

### 解题思路
+ 二分搜索，同样具备"**<font style="color:#E8323C;">分、解、合</font>**"的特性
+ 考虑选择分而治之

### 解题步骤
+ 分：计算中间元素，分割数组
+ 解：递归地在较大或者较小子数组进行二分搜索
+ 合：不需要此步，因为在子数组中搜到就返回了

### 代码实现
`src/algorithm-design/devide-and-conquer/leetcode.ts`

```typescript
// todo 猜数字大小
/** 
 * Forward declaration of guess API.
 * @param {number} num   your guess
 * @return 	            -1 if num is lower than the guess number
 *			             1 if num is higher than the guess number
 *                       otherwise return 0
 * var guess = function(num) {}
 */

function guess(n: number, pick: number) {
  return pick > n ? 1 : pick < n ? -1 : 0;
}

export function guessNumber(n: number, pick: number): any {
  console.time('猜数字大小');
  const rec: any = (start: number, end: number) => {
    if(start> end) return; // 递归结束
    let middle = Math.floor((start + end) / 2);
    const res = guess(middle, pick);
    if(res === 0) {
      console.timeEnd('猜数字大小');
      return middle
    } else if (res === 1) {
      return rec(middle + 1, end);
    } else if(res === -1) {
      return rec(start, middle - 1)
    }
  }
  return rec(0, n);
};
```

## 翻转二叉树
### 题目
+ [翻转二叉树](https://leetcode-cn.com/problems/invert-binary-tree/)

### 解题思路
+ 先翻转左右子树，再将子树换个位置
+ 符合"**<font style="color:#E8323C;">分、解、合</font>**"的特性
+ 考虑选择分而治之

### 解题步骤
+ 分：获取左右子树
+ 解：递归翻转左右子树
+ 合：将翻转后的左右子树换个位置放到根节点上

### 代码实现
`src/algorithm-design/devide-and-conquer/leetcode.ts`

```typescript
// todo 翻转二叉树
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */

 export class TreeNode {
  val: number
  left: TreeNode | null
  right: TreeNode | null
  constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
    this.val = (val===undefined ? 0 : val)
    this.left = (left===undefined ? null : left)
    this.right = (right===undefined ? null : right)
  }
}

export function invertTree(root: TreeNode | null): TreeNode | null {
  if(!root) return null;
  return new TreeNode(
    root.val,
    invertTree(root.right),
    invertTree(root.left)
  );
};
```

## 相同的树
### 题目
+ [相同的树](https://leetcode-cn.com/problems/same-tree/)

### 解题思路
+ 两个树：根节点的值相同，左子树相同，右子树相同
+ 符合"**<font style="color:#E8323C;">分、解、合</font>**"的特性
+ 考虑选择分而治之

### 解题步骤
+ 分：获取两个树的左子树和右子树
+ 解：递归地判读两个树的左子树是否相同，右子树是否相同
+ 合：将上述结果合并，如果跟节点的值也相同，树就相同

### 代码实现
`src/algorithm-design/devide-and-conquer/leetcode.ts`

```typescript
// todo 相同的树
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */
export class TreeNode {
  val: number
  left: TreeNode | null
  right: TreeNode | null
  constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
    this.val = (val===undefined ? 0 : val)
    this.left = (left===undefined ? null : left)
    this.right = (right===undefined ? null : right)
  }
}

export function isSameTree(p: TreeNode | null, q: TreeNode | null): boolean {
  if(!p && !q) return true;
  if(
    p && q && // p 和 q 同时存在
    p?.val === q?.val && // 根节点相同
    isSameTree(p.left, q.left) && // 左子树相同
    isSameTree(p.right, q.right) // 右子树相同
  ) {
    return true;
  }
  return false;
};
```

## 对称二叉树
### 题目
+ [对称二叉树](https://leetcode-cn.com/problems/symmetric-tree/)

### 解题思路
+ 转化为：左右子树是否镜像
+ 分解为：树1的左子树和树2的右子树是否镜像，树1的右子树和树2的左子树是否镜像
+ 符合"**<font style="color:#E8323C;">分、解、合</font>**"的特性
+ 考虑选择分而治之

### 解题步骤
+ 分：获取两个树的左子树和右子树
+ 解：递归地判断树1的左子树和树2的右子树是否镜像，树1的右子树和树2的左子树是否镜像
+ 合：如果上述都成立，且根节点值也相同，两个树就镜像

### 代码实现
`src/algorithm-design/devide-and-conquer/leetcode.ts`

```typescript
// todo 对称二叉树
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 *     constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
 *         this.val = (val===undefined ? 0 : val)
 *         this.left = (left===undefined ? null : left)
 *         this.right = (right===undefined ? null : right)
 *     }
 * }
 */
export class TreeNode {
  val: number
  left: TreeNode | null
  right: TreeNode | null
  constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
    this.val = (val===undefined ? 0 : val)
    this.left = (left===undefined ? null : left)
    this.right = (right===undefined ? null : right)
  }
}

export function isSymmetric(root: TreeNode | null): boolean {
  if(!root) return true;
  const rec = (l: TreeNode | null, r: TreeNode | null): boolean => {
    if(!l && !r) return true; // 递归结束条件
    if(
      l && r &&
      l.val === r.val &&
      rec(l.left, r.right) &&
      rec(l.right, r.left)
    ) {
      return true;
    }
    return false;
  }
  return rec(root.left, root.right);
};
```

# 总结
分而治之是将一个大问题分解为多个与原问题相似且独立的小问题，递归解决小问题，最后将小问题结果合并，则解决了原来的问题。
