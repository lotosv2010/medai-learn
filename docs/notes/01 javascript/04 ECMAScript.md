# 概述
## 简介
+ 通常将ECMAScript看作JavaScript的标准化规范
+ 实际上JavaScript是ECMAScript的扩展语言
+ ECMAScript只是提供了最基本的语法
+ JavaScript语言本身指的就是ECMAScript
