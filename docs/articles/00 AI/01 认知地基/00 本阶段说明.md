## 命名规则

```
docs/articles/00 AI/{阶段序号} {阶段名}/YYYY-MM-DD-{slug}.md
```

文件名按**实际发布日期**取，写之前先定 slug，日期等发布当天再补——所以现在不预先建空文件，避免一堆过期日期。

## 写作顺序

```
读原理（docs/roadmap/ai-agent-learning-roadmap.md）
  → 跑实验（labs/phase1-cognition/）
  → 写文章（本目录）
  → 回填 progress.json
```

两条硬约束：

1. **实验没跑通不落笔**。文章里的 token 数、成本、命中率必须是自己跑出来的真实输出，不能写「一般来说」。
2. **不走 `/publish` 的「笔记 → 文章」流程**。本系列没有笔记目录，输入是实验结论。
