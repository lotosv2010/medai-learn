# throttle(节流)
+ 节流就是保证一段时间内，核心代码只执行一次。
+ 例如：水滴积攒到一定重量才会下落。

## 时间戳方案
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>节流</title>
  <style>
    * {
      padding: 0;
      margin: 0;
    }
    html {
      height: 100%;
    }
    body {
      display: flex;
      align-items: center;
      justify-content: center;
      height: 100%;
    }
    button {
      width: 200px;
      height: 50px;
      line-height: 50px;
    }
  </style>
</head>
<body>
  <button id="btn">点击</button>
  <script>
    // 时间戳方案
    function throttle(fn, waiting) {
      let previous = 0
      return function () {
        let now = Date.now()
        if(now - previous > waiting) {
          fn.apply(this, arguments)
          previous = now
        }
      }
    }

    function logger(e) {
      console.log('click', e, this)
    }
    let btn = document.querySelector('#btn')
    btn.addEventListener('click', throttle(logger, 1000))
  </script>
</body>
</html>
```

```html
      display: flex;
      align-items: center;

    }
    button {
      width: 200px;
      height: 50px;
      line-height: 50px;
    }
  </style>
</head>
<body>
  <button id="btn">点击</button>
  <script>
     // 定时器方案
     function throttle(fn, waiting) {
      let timer = null
      return function () {
        if(!timer) {
          timer = setTimeout(() => {
            fn.apply(this, arguments)
            timer = null
          }, waiting)
        }
      }
    }

    function logger(e) {
      console.log('click', e, this)
    }

    btn.addEventListener('click', throttle(logger, 1000))
  </script>
</body>
</html>
```

# debounce(防抖)
+ 防抖就是一段时间结束后，才触发一次事件，如果一段时间为结束再次触发事件，就会重新开始计算时间。
+ 例如：在电梯中，门快要关了，突然有人准备上来。电梯并没有改变楼层，而是再次打开门。电梯延迟了改变楼层的功能，但优化了资源。

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>防抖</title>
  <style>
    * {
      padding: 0;
      margin: 0;
    }
    html {
      height: 100%;
    }
    body {
      display: flex;
      align-items: center;
      justify-content: center;
      height: 100%;
    }
    button {
      width: 200px;
      height: 50px;
      line-height: 50px;
    }
  </style>
</head>
<body>
  <button id="btn">点击</button>
  <script>
    // 定时器方案
    function debounce(fn, waiting, immediate) {
      let timer = null
      return function () {
        if(timer) {
          clearTimeout(timer)
        } 
        if(immediate) {
          const callNow = !timer
          if(callNow) fn.apply(this, arguments)
        }
        timer = setTimeout(() => {
          fn.apply(this, arguments)
          timer = null
        }, waiting)
      }
    }

    function logger(e) {
      console.log('click', e, this)
    }
    let btn = document.querySelector('#btn')
    // btn.addEventListener('click', debounce(logger, 1000, true))
    btn.addEventListener('click', debounce(logger, 1000))
  </script>
</body>
</html>
```

# requestAnimationFrame
+ 编写动画循环的关键是要知道延迟时间多长合适，如果时间过长会导致动画不流畅，时间过短会造成过度的绘制。
+ `requestAnimationFrame` 采用系统时间间隔，保持最佳绘制效率。
+ 此方法是用来在页面重绘之前，通知浏览器调用一个指定的函数，被调用的频率是约每秒 60 次，在运行时浏览器会自动优化方法的调用。

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>requestAnimationFrame</title>
</head>
<body>
  <canvas id="canvas" width="500px" height="500px"></canvas>
  <script>
    const oC = document.querySelector('#canvas')
    const gd = oC.getContext('2d')
    let left = 100
    function next() {
      gd.clearRect(0, 0, oC.width, oC.height)
      left += 5
      gd.strokeRect(left, 20, 100, 100)
      requestAnimationFrame(next)
    }
    requestAnimationFrame(next)
  </script>
</body>
</html>
```
