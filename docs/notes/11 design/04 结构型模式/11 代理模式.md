# 一、概述
+ 由于一个对象不能直接引用另一个对象，所以需要通过代理对象在这个对象之间起到中介作用
+ 代理模式就是为目标对象创造一个代理对象，以实现对目标对象的访问
+ 这样就可以在代理对象里添加一些逻辑判断、调用前或调用后执行一些操作，从而实现了扩展目标的功能
+ 火车票代购、房产中介、律师、海外代购、明星经纪人

# 二、类图
+ Target：目标对象，也就是被代理的对象，是具体业务的执行者
+ Proxy：代理对象，里面会包含一个目标对象的引用，可以实现对访问的扩展和额外的处理

```typescript
  abstract answerPhone(): void; // 接电话
}

class Angelababy extends IStar {
  available: boolean = !Math.round(Math.random()); // 是否有空
  answerPhone(): void {
    console.log("I am Angelababy");
  }
}
class AngelababyAgent extends IStar {
  // 让经纪人保持一个对angelababy的引用
  constructor(private angelababy: Angelababy = new Angelababy()) {
    super();
  }
  answerPhone(): void {
    console.log("I am  Angelababy Agent");
    // 判断angelababy是否有空
    this.angelababy.available
      ? this.angelababy.answerPhone()
      : console.log("Angelababy Unavailable");
  }
}

const proxy = new AngelababyAgent();
proxy.answerPhone();
```

## 缓存代理
### 阶乘(factorial)
+ 有时候可以用空间换时间
+ 一个正整数的阶乘(factorial)是所有小于及等于该数的正整数的积，并且0的阶乘是1

```typescript
const factorial = function (num: number): number {
  if(num === 1) {
    return 1
  } else {
    return (num * factorial(num - 1))
  }
}

const proxy = function (fn: Function) {
  const cache: Record<string, any> = {}; // 缓存对象
  return function(num: number) {
    console.log(cache)
    if(num in cache) {
      return cache[num];
    }
    return cache[num] = fn.call(this, num);
  }
}

const proxyFactorial = proxy(factorial);
console.time();
console.log(proxyFactorial(50));
console.timeEnd();
console.time();
console.log(proxyFactorial(50));
console.timeEnd();
console.time();
console.log(proxyFactorial(50));
console.timeEnd();
```

### 斐波那契数列(Fibonacci sequence)
+ 斐波那契数列(Fibonacci sequence)指的是这样的一个数列：`1，1，2，3，5，8，13，21，34`。在数学上，斐波那契数列以如下递推的方式定义：`F(1)=1,F(2)=1,F(n)=F(n-1)+F(n-2)(n>3)`

```typescript

function fibonacci(n: number): number {
  return n <= 2 ? 1 : fibonacci(n-1) + fibonacci(n-2);
}


const fibonacciCache = (function() {
  const cache: Record<string, number> = {};
  function fibonacci(n: number): number {
    if(cache[n]) {
      return cache[n];
    }
    const result = n <= 2 ? 1 : fibonacci(n-1) + fibonacci(n-2);
    cache[n] = result;
    return result;
  }
  return fibonacci;
})();
```

## 防抖代理
+ 通过防抖代理优化可以把多个请求合并为一次，提高性能
+ 节流与防抖都是为了减少频繁发事件回调
+ 节流(Throttle)是在某段时间内不管发了多少次回调都只认第一个，并在第一次结束后执行回调
+ 防抖(Debounce)就是在某段时间不管出发了多少回调只看最后一个

### 节流(Throttle)
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .container {
      height: 400px;
      width: 300px;
      border: 1px solid royalblue;
      overflow: auto;
    }
    .content {
      height: 5000px;
    }
  </style>
</head>
<body>
  <div class="container">
    <div class="content"></div>
  </div>
  <script>
    /**
     * 立即执行版（时间戳版）
     * callback 回调函数
     * interval 执行间隔 ，单位毫秒
     */
    function throttle(callback, interval) {
      let last = 0; // 上次执行时间
      return function() {
        const context = this;
        const args = Array.from(arguments);
        const now = Date.now();
        if(now - last > interval) {
          callback.apply(context, args);
          last = now;
        }
      }
    }


     /**
     * 延迟执行版（定时器版）
     * callback 回调函数
     * interval 执行间隔 ，单位毫秒
     */
    function throttle1(callback, interval) {
      let timer; // 上定时器
      return function() {
        const context = this;
        const args = Array.from(arguments);
        if(!timer) {
          timer = setTimeout(() => {
            callback.apply(context, args);
            timer = null;
          }, interval);
        }
      }
    }

    const container = document.querySelector('.container');
    let lastTime = Date.now();
    const scrollEvent = (event) => {
      const nowDate = Date.now();
      console.log(`触发了滚动事件，${(nowDate - lastTime) / 1000} 秒`);
      lastTime = nowDate;
    }
    container.addEventListener('scroll', throttle(scrollEvent, 1000), false);
  </script>
</body>
</html>
```

### 防抖(Debounce)
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    .container {
      height: 400px;
      width: 300px;
      border: 1px solid royalblue;
      overflow: auto;
    }
    .content {
      height: 5000px;
    }
  </style>
</head>
<body>
  <div class="container">
    <div class="content"></div>
  </div>
  <script>
    /**
     * 立即执行版
     * callback 回调函数
     * interval 执行间隔 ，单位毫秒
     */
    function debounce(callback, interval) {
      let timer; // 定时器
      return function() {
        const context = this;
        const args = Array.from(arguments);
        if(timer) {
          clearTimeout(timer);
        }
        const callNow = !timer;
        timer = setTimeout(() => {
          callback.apply(context, args);
          timer = null;
        }, interval);
        if(callNow) callback.apply(context, args);
      }
    }

    const container = document.querySelector('.container');
    let lastTime = Date.now();
    const scrollEvent = (event) => {
      const nowDate = Date.now();
      console.log(`触发了滚动事件，${(nowDate - lastTime) / 1000} 秒`);
      lastTime = nowDate;
    }
    container.addEventListener('scroll', debounce(scrollEvent, 1000), false);
  </script>
</body>
</html>
```

## Proxy
+ Proxy 用于修改某些操作的默认行为
+ Proxy 可以理解成，在目标对象之前架一层<font style="color:#E8323C;">拦截，</font>外界对该对象的访问，都必须先通过这层拦截，因此提供了一种机制，可以对外界的访问进行过滤和改写
+ Proxy 这个词的原意是代理，用在这里表示 `代理` 某些操作，可以译为 `代理器`

```typescript
const girl: Record<string, any> = {
  name: 'robin',
  age: 31,
  height: 160
}

const girlAgent = new Proxy(girl, {
  get(target, key, receiver) {
    if(key === 'age') {
      target[key] = target[key] - 5;
    } else if(key === 'height') {
      target[key] = target[key] + 5;
    }
    return Reflect.get(target, key, receiver);
  },
  set(target, key, value,receiver): boolean {
    if(key === 'boyfriend') {
      if(value.age > 40) {
        throw new Error('年龄太大了');
      } else if(value.salary < 20000) {
        throw new Error('工资太低了');
      }
    }
    return Reflect.set(target, key, value, receiver);
  }
});

console.log(girlAgent.age);
console.log(girlAgent.height);
console.log(girlAgent.name);
girlAgent.boyfriend = {
  age: 30,
  salary: 10000
}
```

## Vue2和Vue3
+ Vue2 中的变化侦测实现对 Object 及 Array 分别进行了不同的处理，Object 使用了 Object.defineProperty() API，Array 使用了拦截器对 Array 原型上的能够改变数据的方法进行拦截，虽然也实现了数据的变化侦测，但存在很多局限，比如对象新增的属性无法被侦测，以及通过数组下标修改数组内容也无法被侦测，也因此在Vue2 中经常会使用 $set 这个方法对数据修改，以确保以来更新。
+ Vue3中使用了 ES6 的 Proxy API 对数据代理，没有像 Vue2 中对原数据进行修改，只是加了代理包装，因此首先性能上有所改善，其次解决了 Vue2 中变化侦测的局限性，可以不使用 $set 新增的对象属性及通过下标修改数组都能被侦测到

## 总结
+ 代理模式 VS 适配器模式，适配器提供不同接口，代理模式提供一模一样的接口
+ 代理模式 VS 装饰器模式，装饰器模式原来的功能不变可以使用，代理模式改变原来的功能
