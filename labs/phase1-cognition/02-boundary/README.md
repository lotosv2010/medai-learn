# 02 — 能力边界

对应文章：第 02 篇《能力边界：幻觉、知识截止与「它不知道自己不知道」》

## 要验证什么

选 3 个「模型大概率不知道」的医疗相关问题（编造的批号、未发布的政策、极冷门的剂量细节），每个问题用**三种问法**各问一次：

| 问法 | prompt 差异 | 想验证的假设 |
|------|------------|-------------|
| 裸问 | 直接问 | 最容易编造 |
| 加约束 | 追加「如果不确定请直接说不知道，不要编造」 | 能减少编造，但不彻底 |
| 给资料 | 附一段真实说明书段落，要求只依据资料回答 | 准确率最高，但可能出现「忠实性幻觉」（资料里有，它答偏） |

## 怎么跑

```bash
pnpm --filter @medai/labs boundary
```

## 看到什么算成功

3 问题 × 3 问法 = 9 条结果，做成矩阵，能明确回答：

- 哪一列编造最多？（应该是裸问）
- 加约束后「我不知道」的比例上升了多少？
- 给资料后是否还有答错的？错在哪（没看到 / 看到了但答偏）？

结论要能直接支撑文章里那句话：**Prompt 只能缓解，资料注入才是根本——而资料注入就是 RAG 的动机。**

## 预算

9 次短调用，预计 ¥1-2。
