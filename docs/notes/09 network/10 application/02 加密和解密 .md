# crypto
+ `crypto` 是 node.js 中实现加密和解密的模块，在 node.js 中，使用 `OpenSSL` 类库作为内部实现加密解密的手段，`OpenSSL` 是一个经过严格测试的可靠的加密与解密算法的实现工具

# 散列(哈希)算法
+ 散列算法也叫哈希算法，用来把任意长度的输入变换成固定长度的输出，常见的有 md5、sha1 等
    - 相同的输入会产生相同的输出
    - 不同的输入会产生不同的输出
    - 任意的输入长度输出长度是相同的
    - 不能从输出推算输入的值

## md5
```javascript
const crypto = require('crypto');
const str = 'hello'; 
const str2 = 'world';
const md5 = crypto.createHash('md5');
// update 指定加密的值
// digest 指定输出的格式base64
const res = md5.update(str).update(str2).digest('base64');
const md52 = crypto.createHash('md5');
// update 指定加密的值
// digest 指定输出的格式16进制
const res2 = md52.update(str).update(str2).digest('hex');
console.log(res)
console.log(res2)
```

# HMAC算法
+ HMAC算法将散列算法与一个密钥结合在一起，以阻止对签名完整性的破坏

## 语法
+ algorithm 是一个可用的摘要算法，例如 sha1、md5、sha256
+ key为一个字符串，用于指定一个PEM格式的密钥

```javascript
const crypto = require('crypto');
const hmac = crypto.createHmac(algorithm, key);
hmac.update(data);
```

## 生成私钥
+ PEM 是 OpenSSL 的标准格式，OpenSSL使用 PEM 文件格式存储证书和密钥，是基于base64编码的证书
+ 常用的生成算法有RSA及DSA，RSA生成的私钥可以用来加密以及签名，而DSA生成的私钥只可以用来签名

### RSA算法生成key
+ genrsa：指定了生成了算法使用RSA
+ -desc：表示生成的key是有密码保护的（注：如果是将生成的key与server的证书一起使用，最好不需要密码，就是不要这个参数，否则其它人就会在请求的时候每次都要求输入密码）
+ -out：后面的参数表示生成的key的输入文件
+ 1024：表示的是生成key的大小，单为字节(bits)

```javascript
openssl genrsa -des3 -out private_key.pem 1024
```

### DSA算法生成key
+ 根据DSA算法生成Key需要两步：
    - 第一步是生成用于生成Key的参数：  
 `openssl dsaparam -out dsaparam.pem 2048`
    - 根据生成的参数生成Key：  
`openssl gendsa -des3 -out privkey.pem dsaparam.pem`

```shell
openssl dsaparam -out dsaparam.pem 2048
openssl gendsa -des3 -out privkey.pem dsaparam.pem
```

## 示例
```javascript
openssl genrsa -out private_key.pem 1024
```

```javascript
const crypto = require('crypto');
const fs = require('fs');
const path = require('path');

const pem = fs.readFileSync(path.join(__dirname, './private_key.pem'));
const key = pem.toString('ascii');
// console.log(key);
const hmac = crypto.createHmac('sha1', key);
const rs = fs.createReadStream(path.join(__dirname, './data.json'));
rs.on('data', (data) => {
  // console.log(data.toString())
  hmac.update(data);
});

rs.on('end', () => {
  const res = hmac.digest('hex');
  console.log(res);
});
```

# 对成加密
+ blowfish 算法是一种对称加密算法，对称的意思就是加密和解密使用的是同一个密钥

<!-- 这是一张图片，ocr 内容为：密文 私钥A 明文 同一私钥 密文 明文 -->
![](https://cdn.nlark.com/yuque/0/2021/png/738210/1637555460505-e284b696-8aef-49e5-9913-8dff855d1a7d.png)

```javascript
const crypto = require('crypto');

// 加密
function genSign(src, key, iv) {
  const cipher = crypto.createCipheriv("aes-128-cbc", key, iv);
  cipher.update(src, "utf8", "hex");
  return cipher.final("hex");
}

// 解密
function deSign(sign, key, iv) {
  const cipher = crypto.createDecipheriv("aes-128-cbc", key, iv);
  cipher.update(sign, "hex", "utf8");
  return cipher.final("utf8");
}

// ase-128-cbc 加密算法要求key和iv长度都为16
const key = Buffer.from('9vApxLk5G3PAsJrM', 'utf8');
const iv = Buffer.from('FnJL7EDzjqWjcaY9', 'utf8');
const sign = genSign('hello world', key, iv);
console.log(sign); // 764a669609b0c9b041faeec0d572fd7a


// 解密
const src=deSign(sign, key, iv);
console.log(src); // hello world
```

# 非对称加密
+ 非对称加密算法需要两个密钥：公开密钥(publickey)和私有密钥(privatekey)
+ 公钥与私钥是一对，如果用公钥对数据进行加密，只有用对应的私钥才能解密，如果用私钥对数据进行加密，只有用对应的公钥才能解密
+ 因为加密和解密使用的是两个不同的密钥，所以这种算法叫非对称加密算法

+ 为私钥创建公钥

```shell
# 创建私钥
openssl genrsa -out private_key.pem 1024
# 创建公钥
openssl pkcs8 -topk8 -inform PEM -in private_key.pem -outform PEM -nocrypt -out public_key.pem
```

```javascript
const crypto = require('crypto');
const fs = require('fs');
const path = require('path');

const str = 'hello world';
const buffer = Buffer.from(str);
const key = fs.readFileSync(path.join(__dirname, './private_key.pem'));
const cert = fs.readFileSync(path.join(__dirname, './public_key.pem'));
const secret = crypto.publicEncrypt(cert, buffer);
console.log(secret);
const res = crypto.privateDecrypt(key, secret);
console.log(res.toString())
```

# 签名
+ 在网络中，私钥的拥有者可以在一段数据被发送之前先对数据进行签名得到一个签名，通过网络把此数据发送给数据接收者之后，数据的接收者可以通过公钥来对该签名进行验证，以确保这段数据是私钥的拥有者所发出的原始数据，且在网络中的传输过程中未被修改。

```shell
# 创建私钥
openssl genrsa -out private_key.pem 1024
# 创建公钥
openssl pkcs8 -topk8 -inform PEM -in private_key.pem -outform PEM -nocrypt -out public_key.pem
```

```javascript
const crypto = require('crypto');
const fs = require('fs');
const path = require('path');

const str = 'hello world';
const private = fs.readFileSync(path.join(__dirname, './private_key.pem'), 'ascii');
const public = fs.readFileSync(path.join(__dirname, './public_key.pem'), 'ascii');
const sign = crypto.createSign('RSA-SHA256');
sign.update(str);
const signed = sign.sign(private, 'hex');
const verify = crypto.createVerify('RSA-SHA256');
verify.update(str);
const verifyResult = verify.verify(public, signed, 'hex');
console.log(verifyResult); // true
```
