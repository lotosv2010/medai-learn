# <font style="color:rgb(51, 51, 51);">备份与恢复</font>
## <font style="color:rgb(51, 51, 51);">mongodump</font>
+ <font style="color:rgb(51, 51, 51);">在Mongodb中我们使用mongodump命令来备份MongoDB数据。该命令可以导出所有数据到指定目录中。</font>

> <font style="color:rgb(119, 119, 119);">mongodump -h dbhost -d dbname -o dbdirectory</font>
>
> + <font style="color:rgb(119, 119, 119);">-h MongDB所在服务器地址，例如：127.0.0.1，当然也可以指定端口号：127.0.0.1:27017</font>
> + <font style="color:rgb(119, 119, 119);">-d 需要备份的数据库实例，例如：test</font>
> + <font style="color:rgb(119, 119, 119);">-o 备份的数据存放位置</font>
>

```shell
mongodump  -d school -o data.dmp
```

## <font style="color:rgb(51, 51, 51);">mongorestore</font>
+ <font style="color:rgb(51, 51, 51);">mongodb使用 mongorestore 命令来恢复备份的数据。</font>
    - <font style="color:rgb(51, 51, 51);">--host MongoDB所在服务器地址</font>
    - <font style="color:rgb(51, 51, 51);">--db -d 需要恢复的数据库实例</font>
    - <font style="color:rgb(51, 51, 51);">最后的一个参数，设置备份数据所在位置</font>

```shell
mongorestore  data.dmp
mongorestore -d school data.bmp/school
```

+ <font style="color:rgb(119, 119, 119);">Mongodump可以backup整个数据库，而mongoexport要对每个collection进行操作，最主要的区别也是选择的标准是mongoexport输出的JSON比Mongodump的BSON可读性更高，进而可以直接对JSON文件进行操作然后还原数据（BSON转换JSON存在潜在兼容问题）。</font>

## <font style="color:rgb(51, 51, 51);">group 分组</font>
```shell
db.runCommand({
        group:{
                ns:集合名称，
                key:分组的键,
                initial:初始值,
                $reduce:分解器
                condition:条件,
                finalize:完成时的处理器
        }
});
```

+ <font style="color:rgb(51, 51, 51);">按城市分组，求每个城市里符合条件的人的年龄总和</font>

```shell
db.runCommand({
        group:{
                ns:'students',
                key:{home:true},
                initial:{total:0},
                $reduce:function(doc,result){
                      result.total += doc.age;   
                },
                condition:{age:{$gt:1}},
                finalize:function(result){
                    result.desc = '本城市的总年龄为'+result.total;
                }
        }
});
```

# <font style="color:rgb(51, 51, 51);">什么固定集合</font>
+ <font style="color:rgb(51, 51, 51);">MongoDB 固定集合（Capped Collections）是性能出色且有着固定大小的集合，对于大小固定，我们可以想象其就像一个环形队列，当集合空间用完后，再插入的元素就会覆盖最初始的头部的元素！</font>

<font style="color:rgb(51, 51, 51);"> </font><!-- 这是一张图片，ocr 内容为：HEAD TAIL B E -->
![](https://cdn.nlark.com/yuque/0/2025/png/738210/1743053579789-b06dc368-0081-4401-915a-27e08c99bd45.png)

## <font style="color:rgb(51, 51, 51);">特性</font>
+ <font style="color:rgb(51, 51, 51);">没有索引</font>
+ <font style="color:rgb(51, 51, 51);">插入和查询速度速度非常快 不需要重新分配空间</font>
+ <font style="color:rgb(51, 51, 51);">特别适合存储日志</font>

## <font style="color:rgb(51, 51, 51);">创建固定集合</font>
+ <font style="color:rgb(51, 51, 51);">我们通过createCollection来创建一个固定集合，且capped选项设置为true：</font>
+ <font style="color:rgb(51, 51, 51);">还可以指定文档个数,加上max:1000属性：</font>
+ <font style="color:rgb(51, 51, 51);">判断集合是否为固定集合: db.logs.isCapped()</font>
+ <font style="color:rgb(51, 51, 51);">size 是整个集合空间大小，单位为【KB】</font>
+ <font style="color:rgb(51, 51, 51);">max 是集合文档个数上线，单位是【个】</font>
+ <font style="color:rgb(51, 51, 51);">如果空间大小到达上限，则插入下一个文档时，会覆盖第一个文档；如果文档个数到达上限，同样插入下一个文档时，会覆盖第一个文档。两个参数上限判断取的是【与】的逻辑。</font>
+ <font style="color:rgb(51, 51, 51);">capped 封顶的</font>

```shell
db.createCollection('logs',{size:50,max:5,capped:true});
```

## <font style="color:rgb(51, 51, 51);">非固定集合转为固定集合</font>
```shell
db.runCommand({convertToCapped:"logs",size:5});
```

# <font style="color:rgb(51, 51, 51);">gridfs</font>
+ <font style="color:rgb(51, 51, 51);">gridfs是mongodb自带的文件系统，使用二进制存储文件。</font>
+ <font style="color:rgb(51, 51, 51);">mongodb可以以BSON格式保存二进制对象。</font>
+ <font style="color:rgb(51, 51, 51);">但是BSON对象的体积不能超过4M。所以mongodb提供了</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">mongofiles</font>`<font style="color:rgb(51, 51, 51);">。它可以把一个大文件透明地分割成小文件（256K），从而保存大体积的数据。</font>
+ <font style="color:rgb(51, 51, 51);">GridFS 用于存储和恢复那些超过16M（BSON文件限制）的文件(如：图片、音频、视频等)。</font>
+ <font style="color:rgb(51, 51, 51);">GridFS 用两个集合来存储一个文件：fs.files与fs.chunks。</font>
+ <font style="color:rgb(51, 51, 51);">每个文件的实际内容被存在chunks(二进制数据)中,和文件有关的meta数据(filename,content_type,还有用户自定义的属性)将会被存在files集合中。</font>

## 上传一个文件
+ <font style="color:rgb(51, 51, 51);">-d 数据库的名称</font>
+ <font style="color:rgb(51, 51, 51);">-l 源文件的位置</font>
+ <font style="color:rgb(51, 51, 51);">put 指定文件名</font>

```shell
mongofiles -d myfiles put test.txt
```

## <font style="color:rgb(51, 51, 51);">获取并下载文件</font>
```shell
mongofiles -d myfiles  get 'test.txt'
```

## <font style="color:rgb(51, 51, 51);">查看所有文件</font>
```shell
mongofiles -d myfiles  list
>db.fs.files.find()
>db.fs.chunks.find({files_id:ObjectId('')})
```

## <font style="color:rgb(51, 51, 51);">删除文件</font>
```shell
mongofiles -d myfiles delete "test.txt"
```
