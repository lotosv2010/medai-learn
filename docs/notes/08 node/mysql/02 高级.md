# <font style="color:rgb(51, 51, 51);">什么是聚合函数</font>
+ <font style="color:rgb(51, 51, 51);">对一组值进行计算，并返回计算后的值，一般用来统计数据</font>

## <font style="color:rgb(51, 51, 51);">SUM</font>
+ <font style="color:rgb(51, 51, 51);">累加所有行的值</font>

```sql
# 计算ID=1的学生的的总分
select SUM(grade)  as '总分' from score where student_id = 1;
```

## <font style="color:rgb(51, 51, 51);">AVG</font>
+ <font style="color:rgb(51, 51, 51);">计算所有行的平均值</font>

```sql
# 计算ID=1的学生的的平均分
select AVG(grade) as '平均分' from score where student_id = 1;
```

## <font style="color:rgb(51, 51, 51);">MAX、MIN</font>
+ <font style="color:rgb(51, 51, 51);">计算所有行的最大值和最小值</font>

```sql
select MAX(grade) 最高分,MIN(grade) 最低分 from score where student_id = 1;
```

## <font style="color:rgb(51, 51, 51);">COUNT</font>
+ <font style="color:rgb(51, 51, 51);">计算值不为NULL的行</font>

```sql
select COUNT(*) from student;
select COUNT(1) from student;
select COUNT(name) from student;
select COUNT(NULL) from student;
```

# <font style="color:rgb(51, 51, 51);">分组</font>
+ <font style="color:rgb(51, 51, 51);">分组查询就是按某列的值进行分组，相同的值分成一组，然后可以对此组内进行求平均、求和等计算</font>

## <font style="color:rgb(51, 51, 51);">语法</font>
```sql
SELECT 列名,查询表达式
FROM  <表名>  
WHERE  <条件>
GROUP BY <分组字段>
HAVING 分组后的过滤条件
ORDER BY 列名 [ASC,DESC]
LIMIT 偏移量,条数
```

+ <font style="color:rgb(51, 51, 51);">SELECT列表中只能包含：</font>
    - <font style="color:rgb(51, 51, 51);">被分组的列</font>
    - <font style="color:rgb(51, 51, 51);">为每个分组返回一个值的表达式，如聚合函数</font>

## <font style="color:rgb(51, 51, 51);">示例</font>
+ <font style="color:rgb(51, 51, 51);">统计每位同学的平均成绩-单列分组</font>

```sql
select student_id,avg(grade) from score group by student_id;
```

+ <font style="color:rgb(51, 51, 51);">统计每门课程的最高分，并按分数从高到低排列</font>

```sql
select course_id,max(grade) 平均分 from score group by course_id order by max(grade) desc
```

+ <font style="color:rgb(51, 51, 51);">统计各省的男女同学人数-多列分组</font>

```sql
select province,gender,COUNT(*) from student group by province,gender
```

## <font style="color:rgb(51, 51, 51);">分组筛选</font>
### <font style="color:rgb(51, 51, 51);">语法</font>
```sql
SELECT  FROM  <表名>
WHERE 
GROUP BY {col_name|expr|position}
HAVING  {col_name|expr|position}
ORDER BY {col_name|expr|position} [ASC|DESC]
LIMIT offset,row_count
```

+ <font style="color:rgb(51, 51, 51);">WHERE用于过滤掉不符合条件的记录</font>
+ <font style="color:rgb(51, 51, 51);">HAVING 用于过滤分组后的记录</font>
+ <font style="color:rgb(51, 51, 51);">GROUP BY用于对筛选后的结果进行分组</font>

### <font style="color:rgb(51, 51, 51);">示例</font>
+ <font style="color:rgb(51, 51, 51);">统计学生人数超过1人的省份</font>

```sql
select province,COUNT(*) from student group by province having COUNT(*)>1
```

+ <font style="color:rgb(51, 51, 51);">不及格次数大于1次的学生</font>

```sql
select student_id,COUNT(*) 不及格次数 from score where grade <60 group by student_id having COUNT(*)>1
```

# <font style="color:rgb(51, 51, 51);">子查询</font>
+ <font style="color:rgb(51, 51, 51);">子查询就是指出现在其它SQL语句中的SELECT语句,必须始终出现在圆括号中</font>

+ <font style="color:rgb(51, 51, 51);">子查询可以返回常量、一行数据、一列数据或其它子查询</font>

## <font style="color:rgb(51, 51, 51);">查询年龄大于平均年龄的学生</font>
```sql
SELECT ROUND(AVG(age),2) FROM student; 

SELECT * from student WHERE age > (SELECT ROUND(AVG(age),2) FROM student)
```

## <font style="color:rgb(51, 51, 51);">ANY SOME ALL</font>
+ <font style="color:rgb(51, 51, 51);">ANY 任何一个</font>
+ <font style="color:rgb(51, 51, 51);">SOME 某些</font>
+ <font style="color:rgb(51, 51, 51);">ALL 全部</font>

```sql
# 年龄大于陕西省任何一位同学
SELECT * from student WHERE age > ANY (SELECT age  FROM student WHERE province = '陕西省');
# 年龄大于陕西省某些同学
SELECT * from student WHERE age > SOME (SELECT age  FROM student WHERE province = '陕西省');
# 年龄大于陕西省所有同学
SELECT * from student WHERE age > ALL (SELECT age  FROM student WHERE province = '陕西省');
```

## <font style="color:rgb(51, 51, 51);">查询一下有考试成绩的学生信息</font>
+ <font style="color:rgb(51, 51, 51);">[IN]</font>
+ <font style="color:rgb(51, 51, 51);">[NOT IN]</font>

```sql
SELECT * FROM student where id in (SELECT distinct student_id from score);
```

+ <font style="color:rgb(51, 51, 51);">[EXISTS]</font>
+ <font style="color:rgb(51, 51, 51);">[NOTEXISTS]</font>

```sql
SELECT * FROM student where EXISTS (SELECT distinct student_id from score where student.id = score.student_id  )
```

## <font style="color:rgb(51, 51, 51);">连接条件</font>
+ <font style="color:rgb(51, 51, 51);">使用ON关键字来设定连接条件，也可以使用WHERE来代替</font>
    - <font style="color:rgb(51, 51, 51);">ON来设定连接条件</font>
    - <font style="color:rgb(51, 51, 51);">也可以使用WHERE来对结果进行过滤</font>

## <font style="color:rgb(51, 51, 51);">内连接</font>
+ <font style="color:rgb(51, 51, 51);">显示左表和右表中符合条件的</font>

```sql
SELECT * FROM student INNER JOIN score ON student.id = score.student_id;
```

## <font style="color:rgb(51, 51, 51);">左外连接</font>
+ <font style="color:rgb(51, 51, 51);">显示左表的全部和右表符合条件的</font>

```sql
SELECT * FROM student LEFT JOIN score ON student.id = score.student_id;
```

## <font style="color:rgb(51, 51, 51);">右外连接</font>
+ <font style="color:rgb(51, 51, 51);">显示右表的全部和左表符合条件的</font>

```sql
SELECT * FROM student RIGHT JOIN score ON student.id = score.student_id;
```

## <font style="color:rgb(51, 51, 51);">多表连接</font>
```sql
SELECT student.name,course.name,score.grade FROM score 
INNER JOIN student ON student.id = score.student_id
INNER JOIN course ON course.id = score.course_id;
```

## <font style="color:rgb(51, 51, 51);">无限分类[自身连接]</font>
### <font style="color:rgb(51, 51, 51);">建表</font>
```sql
CREATE table category(
  id int(11) PRIMARY KEY AUTO_INCREMENT NOT NULL,
  name varchar(50),
  parent_id int(11)
)
```

### <font style="color:rgb(51, 51, 51);">插入语句</font>
```sql
INSERT INTO category(id,name,parent_id)
VALUES (1,'数码产品',0),(2,'服装',0),(3,'食品',0),
(4,'iPad',1),(5,'李宁',2),(6,'康师傅',3);
```

### <font style="color:rgb(51, 51, 51);">查询所有的顶级分类下面分类的数量</font>
```sql
SELECT c1.id,c1.name,COUNT(1) 
FROM category c1 INNER JOIN category c2 ON c1.id = c2.parent_id
WHERE c1.parent_id = 0
GROUP BY c1.id;
```

### <font style="color:rgb(51, 51, 51);">父类变成名称</font>
```sql
SELECT c1.id,c1.name,p.name
FROM category c1 LEFT JOIN category p ON c1.parent_id = p.id
```

## <font style="color:rgb(51, 51, 51);">删除重复记录[多表删除]</font>
```sql
INSERT INTO category(id,name,parent_id)
VALUES
(7,'iPad',1),
(8,'李宁',2),
(9,'康师傅',3);
```

### <font style="color:rgb(51, 51, 51);">子查询找要删除的ID</font>
```sql
SELECT * FROM category c1 LEFT JOIN 
(SELECT id,name from category GROUP BY name HAVING COUNT(1)>1) c2
ON c1.name = c2.name WHERE c1.id != c2.id
```

### <font style="color:rgb(51, 51, 51);">通过IN找要删除的ID</font>
```sql
SELECT * FROM category c1 
WHERE c1.name IN 
(SELECT name from category GROUP BY name HAVING COUNT(1)>1)
AND c1.id NOT IN 
(SELECT MIN(id) from category GROUP BY name HAVING COUNT(1)>1)
```

### <font style="color:rgb(51, 51, 51);">删除重复记录</font>
```sql
DELETE FROM category
WHERE name IN 
(SELECT NAME FROM ( SELECT name from category GROUP BY name HAVING COUNT(1)>1) AS T1 )
AND id NOT IN 
(SELECT id FROM (SELECT MIN(id) id from category GROUP BY name HAVING COUNT(1)>1) AS T2)
```

 SET student.province=province.id
