# /learn 笔记 → 公众号文章转化对照

如果输入是 `/learn` 结构化笔记，按此映射复用现成素材：

| 笔记模块 | 文章转化方式 |
|----------|-------------|
| 一句话总结 | → 文章核心论点 / 金句，开头或结尾 |
| 核心概念 | → 正文主体，拆成 2-N 个递进章节（按知识点数量决定） |
| 面试回答框架 · 标准回答 | → 「💬 面试官视角」的 ✅ 标准答案 |
| 面试回答框架 · 加分回答 | → 🎁 加分答案 |
| 常见追问链 | → 章节内的追问 or 文末互动问题 |
| 代码演示 | → 精选核心片段（≤15 行一块）+ 逐行解读，完整保留，超长则拆块 |
| 在本项目中的应用 | → 🔧 真实场景段落 |
| 易混淆点 | → 对比表格，做成「一张图看懂」 |
| 自测题 | → 文末「📝 留个问题」 |

## 识别 /learn 格式的特征

笔记中含有以下模块标题之一即视为 `/learn` 结构化笔记：
- `面试回答框架`
- `常见追问链`
- `在本项目中的应用`
- `一句话总结`（配合其他模块出现时）

识别到后，直接复用这些现成素材填入文章对应位置，无需重新提炼。
