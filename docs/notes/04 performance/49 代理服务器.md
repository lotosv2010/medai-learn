# 什么是代理
+ <font style="color:rgb(51, 51, 51);">代理其实就是一个中介，A和B本来可以直连，中间插入一个C，C就是中介</font>
+ <font style="color:rgb(51, 51, 51);">刚开始的时候，代理多数是帮助内网client访问外网server用的</font>
+ <font style="color:rgb(51, 51, 51);">后来出现了反向代理，"反向"这个词在这儿的意思其实是指方向相反，即代理将来自外网客户端的请求转发到内网服务器，从外到内</font>

# 正向代理
+ <font style="color:rgb(51, 51, 51);">正向代理类似一个跳板机，代理访问外部资源</font>
+ <font style="color:rgb(51, 51, 51);">比如我们国内访问谷歌，直接访问访问不到，我们可以通过一个正向代理服务器，请求发到代理服，代理服务能够访问谷歌，这样由代理去谷歌取到返回数据，再返回给我们，这样我们就能访问谷歌了</font>
+ **<font style="color:rgb(51, 51, 51);">正向代理的用途：</font>**
    - <font style="color:rgb(51, 51, 51);">访问原来无法访问的资源，如google</font>
    - <font style="color:rgb(51, 51, 51);">可以做缓存，加速访问资源</font>
    - <font style="color:rgb(51, 51, 51);">对客户端访问授权，上网进行认证</font>
    - <font style="color:rgb(51, 51, 51);">代理可以记录用户访问记录（上网行为管理），对外隐藏用户信息</font>

# 反向代理
+ <font style="color:rgb(51, 51, 51);">反向代理（Reverse Proxy）实际运行方式是指以代理服务器来接受internet上的连接请求，然后将请求转发给内部网络上的服务器，并将从服务器上得到的结果返回给internet上请求连接的客户端，此时代理服务器对外就表现为一个服务器</font>
+ **反向代理的作用**
    - <font style="color:rgb(51, 51, 51);">保证内网的安全，阻止web攻击，大型网站，通常将反向代理作为公网访问地址，Web服务器是内网</font>
    - <font style="color:rgb(51, 51, 51);">负载均衡，通过反向代理服务器来优化网站的负载</font>

# 源码实现
## src
### index.js
```javascript
const http = require('http');
const httpProxy = require('http-proxy');
const proxy = httpProxy.createProxyServer(); 

const app = http.createServer((req, res) => {
  proxy.web(req, res, {
    target: 'http://localhost:8089'
  });
  proxy.on('error', (error) => {
    console.log('代理服务器出错');
    console.log(error.toString());
  })
});
app.listen(8088, () => {
  console.log(`server start port 8088`);
});

```

### proxy.js
```javascript
const http = require('http');

const app = http.createServer((req, res) => {
  res.end(req.url);
});
app.listen(8089, () => {
  console.log(`server start port 8089`);
});
```

## proxy.web实现
```javascript
const http = require('http');
const url = require('url');

function web(req, res, options) {
  const {host, port, pathname: path} = url.parse(req.url);
  const {method, headers} = req;
  const opts = {
    host,
    port,
    method,
    path,
    headers
  }
  opts.host = options.target;
  http.request(opts, (response) => {
    response.pipe(res);
  });
}
```

# 总结
+ 正向代理即是客户端代理, 代理客户端, 服务端不知道实际发起请求的客户端.
+ 反向代理即是服务端代理, 代理服务端, 客户端不知道实际提供服务的服务端
