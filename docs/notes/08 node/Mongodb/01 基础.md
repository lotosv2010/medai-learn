# 什么是MongoDB
+ MongoDB是一个基于分布式文件存储的开源数据库系统
+ MongoDB将数据存储为一个文档，数据结构由键值(key => value)对组成。MongoDB文档类似于JSON对象。字段值可以包含其他文档，数组以及文档数组。

# 基本概念
+ <font style="color:#F5222D;">数据库</font> MongoDB的单个实例可以容纳多个独立的数据库，比如一个学生管理系统就可以对应一个数据库实例
+ <font style="color:#F5222D;">集合</font> 数据库是由集合组成的，一个集合用来表示一个<font style="color:#F5222D;">实体，</font>如学生集合
+ <font style="color:#F5222D;">文档</font> 集合是由文档组成的，一个文档表示一条<font style="color:#F5222D;">记录</font>，比如一位同学张三就是一个文档

| MongoDB | mysql |
| --- | --- |
| 文档(document)(单个文档最大16M) | 记录(row) |
| 集合(collection) | 表(table) |
| 数据库(database)(32位系统上，一个数据的文件大小不能超过2G) | 数据库(database) |

## 更新文档

### 参数说明
+ **<font style="color:rgb(51, 51, 51);">query </font>**<font style="color:rgb(51, 51, 51);">: update的查询条件，类似sql update查询内where后面的。</font>
+ **<font style="color:rgb(51, 51, 51);">update</font>****<font style="color:rgb(51, 51, 51);"> </font>**<font style="color:rgb(51, 51, 51);">: update的对象和一些更新的操作符（如$,$inc...）等，也可以理解为sql update查询内set后面的</font>
+ **<font style="color:rgb(51, 51, 51);">upsert</font>****<font style="color:rgb(51, 51, 51);"> </font>**<font style="color:rgb(51, 51, 51);">: 可选，这个参数的意思是，如果不存在update的记录，是否插入objNew,true为插入，默认是false，不插入。</font>
+ **<font style="color:rgb(51, 51, 51);">multi</font>****<font style="color:rgb(51, 51, 51);"> </font>**<font style="color:rgb(51, 51, 51);">: 可选，mongodb 默认是false,只更新找到的第一条记录，如果这个参数为true,就把按条件查出来多条记录全部更新。</font>
+ **<font style="color:rgb(51, 51, 51);">writeConcern </font>**<font style="color:rgb(51, 51, 51);">:可选，抛出异常的级别。</font>

### 使用
```shell

```

### 更新操作符
+ <font style="color:#F5222D;">$set操作符</font>: 用来指定一个键并更新键值，若键不存在并创建。

```shell
db.teacher.update({_id: '1'},{$set:{'name': 'mongoDB'}})
```

+ <font style="color:#F5222D;">$inc操作符</font>: 在原基础上累加。

```shell
db.teacher.update({},{$inc:{'age':'1'}})
```

+ <font style="color:#F5222D;">$unset操作符</font>: 删除指定的键。

```shell
db.teacher.update({},{$unset:{'age':'1'}})
```

+ <font style="color:#F5222D;">$push操作符</font>: 向数组中添加元素。

```shell
db.teacher.update({},{$set:{'hobbys':[]}}, {multi: true})
db.teacher.update({},{$push:{'hobbys': 'rading'}}, {multi: true})
```

+ <font style="color:#F5222D;">$ne操作符</font>: 类似mysql的not in 或 not exists。

```shell
db.teacher.update({hobbys: {$ne: 'palying'}},{$push:{'hobbys': 'playing'}}, {multi: true})
```

+ <font style="color:#F5222D;">$addToSet操作符</font>: 向集合中添加元素。

```shell
db.teacher.update({name: 'mongoDB'},{$addToSet:{'hobbys': 'playing'}})
```

+ <font style="color:#F5222D;">$each操作符</font>: 把数组中的元素逐个添加到集合中。

```shell
var hobbys = ['reading', 'writing']
db.teacher.update({name: 'mongoDB'},{$addToSet:{'hobbys': {$each: hobbys}}})
```

+ <font style="color:#F5222D;">$pop操作符</font>: 删除数组中的一项。

```shell
db.teacher.update({_id: '1'},{$pop:{'hobbys': 1}})
```

+ 修改指定索引的元素

```shell
db.teacher.update({_id: '1'},{$set:{'hobbys.0': 'play'}})
```

```shell
var cursor = db.teacher.find()
```

### 正则运算
如果想实现模糊查询，必须使用正则表达式，而且正则表达式使用的语言是Perl兼容的正则表达式的形式。

要实现正则使用，则按照如下的定义格式：

+ 基础语法：{key : 正则标记}
+ 完整语法：{key : {"$regex" : 正则标记, "$options" : 选项}}

options主要是设置正则的信息查询标记：

+ “i”：忽略字母大小写；
+ “m”：多行查找；
+ “x”：空白字符串除了被转义的或在字符类中以外的完全被忽略；如果内容里面不存在换行符号（例如 \n）或者构造上没有（start/end），该选项没有任何效果；
+ “s”：匹配所有的字符（正则中圆点表示匹配任意字符，即“.”），包括换行内容。

对于 i 和 m 可以直接使用，而"x"和“s” 必须使用“$regex”。

```shell
db.teacher.find({"name" : /1/}).pretty()
```

### 分页显示
在MongoDB里面的数据分页显示也是符合于大数据要求的操作函数：

+ skip(n)：表示跨过多少数据行
+ limit(n)：取出的数据行的个数限制

```shell
db.teacher.find().skip(0).limit(3).sort({"age" : -1}).pretty()　　
# 跨过0条，显示3条，年龄按降序排列
```

# 备份与导出
## 备份(mongodump)
+ <font style="color:rgb(51, 51, 51);">mongodump命令脚本语法如下：</font>

```shell
mongodump -h dbhost -d dbname -o dbdirectory
```

+ **<font style="color:rgb(51, 51, 51);">-h：</font>**<font style="color:rgb(51, 51, 51);">MongoDB 所在服务器地址，例如：127.0.0.1，当然也可以指定端口号：127.0.0.1:27017</font>
+ **<font style="color:rgb(51, 51, 51);">-d：</font>**<font style="color:rgb(51, 51, 51);">需要备份的数据库实例，例如：test</font>
+ **<font style="color:rgb(51, 51, 51);">-o：</font>**<font style="color:rgb(51, 51, 51);">备份的数据存放位置，例如：c:\data\dump，当然该目录需要提前建立，在备份完成后，系统自动在dump目录下建立一个test目录，这个目录里面存放该数据库实例的备份数据。</font>

## 恢复(mongorestore)
+ <font style="color:rgb(51, 51, 51);">mongorestore命令脚本语法如下：</font>

```shell
mongorestore -h <hostname><:port> -d dbname <path>
```

# 权限
## 权限概述
+ <font style="color:rgb(18, 18, 18);">在 MongoDB 里面的用户是属于数据库的，每个数据库都有自己的管理员。管理员登录后，只能操作所属的数据库。</font>
+ <font style="color:rgb(18, 18, 18);">注意：在 admin 的数据库中创建的用户是超级管理员，登陆后可以操作任何的数据库。</font>

## 查看所有用户
```shell
use admin
show users
或
db.system.users.find()
或
db.getUsers();
```

## 创建用户
+ <font style="color:rgb(18, 18, 18);">选择数据库</font>
    - <font style="color:rgb(18, 18, 18);">use 数据库的名称</font>
+ <font style="color:rgb(18, 18, 18);">添加用户</font>
    - db.createUser(user, writeConcern)
        * <font style="color:rgb(51, 51, 51);">user：这个文档创建关于用户的身份认证和访问信息；</font>
        * <font style="color:rgb(51, 51, 51);">writeConcern：这个文档描述保证MongoDB提供写操作的成功报告。</font>

```shell
{ user: "<name>",
  pwd: "<cleartext password>",
  customData: { <any information> },
  roles: [
    { role: "<role>", db: "<database>" } | "<role>",
    ...
  ]
}
```

+ <font style="color:rgb(18, 18, 18);">注意点：在创建用户之前，必须先创建一个超级管理员。</font>
+ <font style="color:rgb(51, 51, 51);">user文档字段介绍：</font>
    - <font style="color:rgb(51, 51, 51);">user字段，为新用户的名字；</font>
    - <font style="color:rgb(51, 51, 51);">pwd字段，用户的密码；</font>
    - <font style="color:rgb(51, 51, 51);">cusomData字段，为任意内容，例如可以为用户全名介绍；</font>
    - <font style="color:rgb(51, 51, 51);">roles字段，指定用户的角色，可以用一个空数组给新用户设定空角色；</font>



+ <font style="color:rgb(0, 0, 0);">Built-In Roles（内置角色）：</font>
    - <font style="color:rgb(0, 0, 0);">数据库用户角色：read、readWrite;</font>
    - <font style="color:rgb(0, 0, 0);"> 数据库管理角色：dbAdmin、dbOwner、userAdmin；</font>
    - <font style="color:rgb(0, 0, 0);">集群管理角色：clusterAdmin、clusterManager、clusterMonitor、hostManager；</font>
    - <font style="color:rgb(0, 0, 0);">备份恢复角色：backup、restore；</font>
    - <font style="color:rgb(0, 0, 0);">所有数据库角色：readAnyDatabase、readWriteAnyDatabase、userAdminAnyDatabase、dbAdminAnyDatabase</font>
    - <font style="color:rgb(0, 0, 0);"> 超级用户角色：root   // 这里还有几个角色间接或直接提供了系统超级用户的访问（dbOwner 、userAdmin、userAdminAnyDatabase）</font>
    - <font style="color:rgb(0, 0, 0);">内部角色：__system</font>

<font style="color:rgb(0, 0, 0);"></font>

+ <font style="color:rgb(0, 0, 0);">具体角色的功能： </font>
    - <font style="color:rgb(0, 0, 0);">Read：允许用户读取指定数据库；</font>
    - <font style="color:rgb(0, 0, 0);">readWrite：允许用户读写指定数据库；</font>
    - <font style="color:rgb(0, 0, 0);">dbAdmin：允许用户在指定数据库中执行管理函数，如索引创建、删除，查看统计或访问system.profile；</font>
    - <font style="color:rgb(0, 0, 0);">userAdmin：允许用户向system.users集合写入，可以找指定数据库里创建、删除和管理用户；</font>
    - <font style="color:rgb(0, 0, 0);">clusterAdmin：只在admin数据库中可用，赋予用户所有分片和复制集相关函数的管理权限；</font>
    - <font style="color:rgb(0, 0, 0);">readAnyDatabase：只在admin数据库中可用，赋予用户所有数据库的读权限；</font>
    - <font style="color:rgb(0, 0, 0);">readWriteAnyDatabase：只在admin数据库中可用，赋予用户所有数据库的读写权限；</font>
    - <font style="color:rgb(0, 0, 0);">userAdminAnyDatabase：只在admin数据库中可用，赋予用户所有数据库的userAdmin权限；</font>
    - <font style="color:rgb(0, 0, 0);">dbAdminAnyDatabase：只在admin数据库中可用，赋予用户所有数据库的dbAdmin权限；</font>
    - <font style="color:rgb(0, 0, 0);">root：只在admin数据库中可用。超级账号，超级权限；</font>

```shell
use admin
db.createUser({
  user:'user',
  pwd:'passwd', 
  roles:[
    {role:'readWrite', db:'demo'},
    'read'
  ]
})
```

## <font style="color:rgb(18, 18, 18);">验证权限(用户登录)</font>

    - <font style="color:rgb(18, 18, 18);">如果你是直接启动的方式，则停止服务，重新启动，在启动时也要添加 --auth 选项，auth 表示要开启权限认证</font>
+ <font style="color:rgb(18, 18, 18);">如何通过权限验证</font>
    - <font style="color:rgb(18, 18, 18);">选择数据库</font>
    - <font style="color:rgb(18, 18, 18);">执行db.auth (用户名,密码)</font>

# 附录
## ObjectId构成
+ 之前我们使用MySQL等关系型数据库时，主键都是设置成自增的。但是分布式环境下，这种方法就不可行了，会产生冲突。为此，MongoDB采用了一个称之为ObjectId的类型来做主键。ObjectId是一个12字节的BSON类型字符串。按照字节顺序，依次代表：
    - 4字节：UNIX时间戳
    - 3字节：表示运行MongoDB的机器
    - 2字节：表示生成_id的进程
    - 3字节：由一个随机数开始的计数器生成的值
