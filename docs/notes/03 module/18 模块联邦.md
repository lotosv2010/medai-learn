# <font style="color:rgb(51, 51, 51);">动机</font>
+ <font style="color:rgb(51, 51, 51);">Module Federation的动机是为了不同开发小组间共同开发一个或者多个应用</font>
+ <font style="color:rgb(51, 51, 51);">应用将被划分为更小的应用块，一个应用块，可以是比如头部导航或者侧边栏的前端组件，也可以是数据获取逻辑的逻辑组件</font>
+ <font style="color:rgb(51, 51, 51);">每个应用块由不同的组开发</font>
+ <font style="color:rgb(51, 51, 51);">应用或应用块共享其他其他应用块或者库</font>

# <font style="color:rgb(51, 51, 51);">Module Federation</font>
+ <font style="color:rgb(51, 51, 51);">使用Module Federation时，每个应用块都是一个独立的构建，这些构建都将编译为容器</font>
+ <font style="color:rgb(51, 51, 51);">容器可以被其他应用或者其他容器应用</font>
+ <font style="color:rgb(51, 51, 51);">一个被引用的容器被称为</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">remote</font>`<font style="color:rgb(51, 51, 51);">, 引用者被称为</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">host</font>`<font style="color:rgb(51, 51, 51);">，</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">remote</font>`<font style="color:rgb(51, 51, 51);">暴露模块给</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">host</font>`<font style="color:rgb(51, 51, 51);">,</font><font style="color:rgb(51, 51, 51);"> </font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">host</font>`<font style="color:rgb(51, 51, 51);">则可以使用这些暴露的模块，这些模块被成为</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">remote</font>`<font style="color:rgb(51, 51, 51);">模块</font>

# <font style="color:rgb(51, 51, 51);">实战</font>
## <font style="color:rgb(51, 51, 51);">配置参数</font>
| **<font style="color:rgb(51, 51, 51);">字段</font>** | **<font style="color:rgb(51, 51, 51);">类型</font>** | **<font style="color:rgb(51, 51, 51);">含义</font>** |
| :--- | :--- | :--- |
| <font style="color:rgb(51, 51, 51);">name</font> | <font style="color:rgb(51, 51, 51);">string</font> | <font style="color:rgb(51, 51, 51);">是必须的，这个字段表示该模块在远程应用中的名称，其他远程应用将使用这个名称来引用该模块。name的值将作为远程应用的前缀，即其他应用中使用该模块的路径将是${name}/${expose}</font> |
| <font style="color:rgb(51, 51, 51);">library</font> | <font style="color:rgb(51, 51, 51);">object</font> | <font style="color:rgb(51, 51, 51);">一个对象，它指定了模块在使用webpack模块联邦时在全局范围内注册的名称。这个名称在UMD模块中使用，确保该模块可以通过脚本标记或使用类似require的函数来访问</font> |
| <font style="color:rgb(51, 51, 51);">filename</font> | <font style="color:rgb(51, 51, 51);">string</font> | <font style="color:rgb(51, 51, 51);">构建输出的文件名，指定输出的文件名。</font> |
| <font style="color:rgb(51, 51, 51);">remotes</font> | <font style="color:rgb(51, 51, 51);">object</font> | <font style="color:rgb(51, 51, 51);">远程应用的别名映射。这个对象将其他远程应用的名称作为键，将别名作为值。当一个远程应用需要使用其他应用中的模块时，就可以使用这些别名来引用这些模块</font> |
| <font style="color:rgb(51, 51, 51);">exposes</font> | <font style="color:rgb(51, 51, 51);">object</font> | <font style="color:rgb(51, 51, 51);">被远程应用引用时可以暴露的模块和文件。这个对象将模块和文件名作为键，将暴露的名称作为值</font> |
| <font style="color:rgb(51, 51, 51);">shared</font> | <font style="color:rgb(51, 51, 51);">object</font> | <font style="color:rgb(51, 51, 51);">共享依赖项，这个对象指定了与其他应用程序共享的第三方依赖项。这可以避免在不同的应用程序中加载相同的依赖项，从而减少页面加载时间和文件大小</font> |

      name: 'remote',
      filename: 'remoteEntry.js',
      exposes: {

# <font style="color:rgb(51, 51, 51);">shared</font>
+ <font style="color:rgb(51, 51, 51);">shared是Webpack 5中ModuleFederationPlugin提供的一个配置项，它允许开发人员在多个应用程序之间共享依赖关系，减少冗余代码和减小构建大小</font>
+ <font style="color:rgb(51, 51, 51);">使用shared配置项，我们可以将依赖项列表指定为一个对象，其中每个属性的名称是依赖项的名称，而属性的值指定了如何共享这些依赖项。shared对象的属性可以有以下几个值</font>
    - `<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">singleton</font>`<font style="color:rgb(51, 51, 51);">：表示这个依赖项是共享的，并且只有一个实例。这个选项可以确保这个依赖项在所有应用程序中都只被加载一次</font>
        * `<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">requiredVersion</font>`<font style="color:rgb(51, 51, 51);">：表示这个依赖项需要的版本号。如果版本号不匹配，Webpack会抛出一个错误</font>
    - `<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">import</font>`<font style="color:rgb(51, 51, 51);">：指定从哪个应用程序中导入这个依赖项。这个选项需要使用一个字符串，表示其他应用程序的名称</font>
    - `<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">shareKey</font>`<font style="color:rgb(51, 51, 51);">：指定共享依赖项的名称。如果没有指定，那么这个依赖项的名称将使用其自身的名称</font>
+ <font style="color:rgb(51, 51, 51);">如果一个应用程序依赖于另一个应用程序，那么这些依赖关系应该由remotes选项来指定，而不是由shared选项来指定。shared选项只应该用于共享依赖关系，而不是应用程序之间的依赖关系</font>
+ <font style="color:rgb(51, 51, 51);">使用</font>`<font style="color:rgb(111, 89, 144);background-color:rgb(237, 237, 247);">shareKey</font>`<font style="color:rgb(51, 51, 51);">选项可以确保我们使用自定义名称来共享依赖项。这个选项可以用于避免依赖项名称冲突，并允许我们使用更具有描述性的名称来引用共享依赖项</font>
