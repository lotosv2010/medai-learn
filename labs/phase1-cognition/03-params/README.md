# 03 — 采样参数与推理模型

对应文章：第 03 篇《采样参数与推理模型：temperature 到底在调什么》

## 要验证什么

### 实验 A：temperature 扫描

固定一个 prompt（如「给这款药写一条 30 字以内的用药提醒」），temperature 取 `0 / 0.3 / 0.7 / 1.0`，每档跑 5 次，共 20 条输出。

记录：同一档位内 5 条输出的重复率、偏离程度、是否出现事实偏移。

预期看到：0 档几乎完全一致；1.0 档偶尔出现「不像事实」的表述。

> ⚠️ **关键前提：这一组必须关掉思考模式（`thinking: disabled`）。**
> 现行 DeepSeek API 的思考模式默认开启，而思考模式下 `temperature` 被忽略——传了不报错，但也不会生效。
> 不关掉的话，四个档位的输出会几乎一模一样，你会得出「温度没用」这个错误结论。

### 实验 B：思考关闭 vs 思考开启

V4 系列把推理能力做成了**开关**，不再是 `deepseek-reasoner` 那样的另一个模型名。所以这里用同一个模型跑两组：

- 多步剂量计算题（按体重折算，并判断是否超过成人上限）
- 一道简单题（阿莫西林属于哪类抗生素）作对照

记录四项：**耗时 / 输出 token / 思考 token / 成本**。

预期看到：多步题上思考模式明显更稳，但慢几倍、贵几倍；简单题上两者几乎拉不开差距。

## 怎么跑

```bash
pnpm --filter @medai/labs params
```

## 看到什么算成功

- 一张「temperature 档位 × 输出差异」表
- 一张「思考关闭 / 开启」四项对比表（多步题 + 简单题各一张）
- 你能回答：为什么 temperature=0 也不保证完全确定？

## 预算

20 次短调用 + 4 次对照调用（其中 2 次开启思考，思考 token 计入输出），预计 ¥2-3。

> 定价按 `deepseek-flash` 非高峰档估算：输入 ¥1 / 输出 ¥4（元 / 百万 token）。
> 工作日北京时间 09:00-12:00、14:00-18:00 为高峰时段，价格翻倍——想省钱就避开这两段跑。
